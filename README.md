# Personal Portfolio Website

This repository powers my GitHub Pages site:  
https://chuck-sylvester.github.io

The site is built using GitHub Pages + Jekyll and written primarily in Markdown.

## Planned Structure (to be developed)
- `index.md` – home page
- `services.md` – consulting services
- `portfolio.md` – sample work and projects
- `about.md` – background and contact
- `_config.yml` – site configuration
- `_posts/` – optional blog posts

## Local Development
To develop locally, install Ruby + Bundler, then run:  

```bash
bundle install
bundle exec jekyll serve
```
